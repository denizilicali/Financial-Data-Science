# Financial Data Science

Problem sets from the Financial Data Science course Summer Semester 26.

| | Topic |
|---|---|
| ProblemSet1 | Strategic portfolio (mean-variance, efficient frontier) |
| ProblemSet2 | Risk measures with stochastic volatility (Kalman filter, EGARCH, VaR / ES) |
| ProblemSet3 | Implied moments from options (BKM 2003) |
| ProblemSet4 | Portfolio sorts |
| ProblemSet5 | News events and volatility (post-LASSO) |
| ProblemSet6 | Machine learning return prediction |

Each folder contains the original submission files (notebooks, reports, code, and outputs).
